2.1 理论讲解

2.1.1 ChatModel 统一抽象

Solon-AI 的核心是 ChatModel，它提供了：

  • 统一接口：无论底层是 OpenAI、Ollama 还是 DeepSeek，调用方式一致
  • 方言适配：通过 provider 指定供应商，框架自动处理协议差异
  • 响应式支持：同步 call() 和响应式 stream() 两种模式

2.1.2 核心概念

概念 说明 示例
ChatModel LLM 客户端入口 ChatModel.of(url).provider("ollama").build()
ChatMessage 消息封装（System/User/Assistant） ChatMessage.ofUser("你好")
ChatResponse 响应结果（包含消息、usage、finishReason） response.getMessage()
ChatOptions 调用选项（temperature、tools、talents） .options(op -> op.temperature(0.7))
Prompt 提示词构建器 chatModel.prompt("hello")

2.1.3 流式调用（Reactive）

// 流式调用返回 Flux<ChatEvent>
Flux<ChatEvent> flux = chatModel.prompt("讲个故事")
        .stream();

// 订阅事件
flux.subscribe(event -> {
    if (event instanceof ChatEventContent) {
        System.out.print(((ChatEventContent) event).getContent());
    }
});

2.2 实践练习

练习1：多轮对话（带上下文）

import org.noear.solon.ai.chat.ChatModel;
import org.noear.solon.ai.chat.ChatMessage;
import org.noear.solon.ai.chat.ChatResponse;

import java.util.ArrayList;
import java.util.List;

public class MultiTurnChat {
    public static void main(String[] args) {
        ChatModel chatModel = ChatModel.of("http://127.0.0.1:11434/api/chat")
                .provider("ollama")
                .model("qwen2.5:1.5b")
                .build();

        // 1. 维护对话历史
        List<ChatMessage> history = new ArrayList<>();

        // 第一轮
        ChatMessage user1 = ChatMessage.ofUser("我叫小明，是一名 Java 工程师");
        ChatMessage assistant1 = chatModel.prompt(user1).call().getMessage();
        history.add(user1);
        history.add(assistant1);

        System.out.println("AI: " + assistant1.getContent());

        // 第二轮（测试记忆）
        ChatMessage user2 = ChatMessage.ofUser("我叫什么名字？我是做什么的？");
        ChatResponse response2 = chatModel.prompt(user2)
                .options(op -> op.chatMessages(history))
                .call();

        System.out.println("AI: " + response2.getMessage().getContent());
    }
}

练习3：函数调用（Function Calling）

import org.noear.solon.ai.chat.tool.ToolProvider;
import org.noear.solon.ai.chat.tool.ToolExecutable;

public class FunctionCallingDemo {

    // 定义工具
    static ToolProvider weatherTool = ToolProvider.of("get_weather")
            .description("获取指定城市的天气信息")
            .param("city", String.class, "城市名称", true)
            .executable((ToolExecutable) args -> {
                String city = args.getString("city");
                return "{\"city\":\"" + city + "\",\"temp\":25,\"weather\":\"晴\"}";
            });

    public static void main(String[] args) {
        ChatModel chatModel = ChatModel.of("http://127.0.0.1:11434/api/chat")
                .provider("ollama")
                .model("qwen2.5:1.5b")
                .build();

        // 注入工具
        ChatResponse response = chatModel.prompt("北京今天天气怎么样？")
                .options(op -> op.toolAdd(weatherTool))
                .call();

        System.out.println(response.getMessage());
        System.out.println("工具调用: " + response.getToolCalls());
    }
}

2.3 项目实战

实战任务：智能问答机器人

实现一个命令行智能问答机器人，具备以下功能： - 多轮对话记忆（最近 10 轮） - 支持 System Prompt 切换（助手模式/专家模式/创意模式） - 温度参数动态调整 - 对话历史持久化到文件

核心代码骨架：

public class QABot {
    private final ChatModel chatModel;
    private final List<ChatMessage> history = new ArrayList<>();
    private final int MAX_HISTORY = 10;

    public QABot(ChatModel chatModel) {
        this.chatModel = chatModel;
    }

    public String chat(String userInput, String mode) {
        // 1. 根据模式选择 System Prompt
        String systemPrompt = getSystemPrompt(mode);

        // 2. 构建消息列表
        List<ChatMessage> messages = new ArrayList<>();
        messages.add(ChatMessage.ofSystem(systemPrompt));
        messages.addAll(history);
        messages.add(ChatMessage.ofUser(userInput));

        // 3. 调用模型
        ChatResponse response = chatModel.prompt(messages)
                .options(op -> op.temperature(getTemperature(mode)))
                .call();

        // 4. 更新历史
        updateHistory(userInput, response.getMessage());

        return response.getMessage().getContent();
    }

    private void updateHistory(String userInput, ChatMessage assistantMsg) {
        history.add(ChatMessage.ofUser(userInput));
        history.add(assistantMsg);

        // 保持最近 10 轮
        while (history.size() > MAX_HISTORY * 2) {
            history.remove(0);
        }
    }
}

第2章 注意事项

  1. 无状态调用：ChatModel 本身不保存对话历史，多轮对话必须手动维护 List<ChatMessage> 并传入。
  2. 流式事件类型：stream() 返回 Flux<ChatEvent>，常见子类型有 ChatEventContent（文本片段）、ChatEventThinking（推理过程）、ChatEventError（错误），需逐一判断处理。
  3. System Prompt 覆盖：system() 方法不会追加，而是替换已有的 system 消息；多次调用只有最后一次生效。
  4. maxTokens 非硬上限：部分模型（如 DeepSeek-R1 的思维链）可能超出 maxTokens 限制，需结合 finishReason 判断是否真正截断。
  5. Function Calling 模型门槛：并非所有模型都支持工具调用，qwen2.5:1.5b 支持较好，但 0.5b 等极小参数模型工具调用准确率显著下降。

第2章 实战作业

作业1：基础巩固

基于"多轮对话"示例，实现一个命令行聊天工具，支持以下命令： - /clear：清空对话历史 - /history：打印当前对话历史（User/Assistant 交替） - /save <file>：将历史保存到 Markdown 文件

作业2：拓展应用

为多轮对话添加滑动窗口策略： - 配置 MAX_HISTORY_ROUNDS = 5 - 只保留最近 5 轮（10 条消息），超出部分自动丢弃 - 在丢弃前将旧消息摘要为一段文本，插入到 system prompt 中，实现"长期记忆压缩"

作业3：动手实践

实现一个支持 stream / non-stream 双模式的命令行聊天工具： - 默认非 stream 模式，整段输出 - 输入 :stream 切换为流式模式，逐字打印 - 流式模式下实时显示 token 计数和耗时 - 将每次对话记录追加到 chat-log.jsonl
