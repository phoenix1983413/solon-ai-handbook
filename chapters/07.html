7.1 理论讲解

7.1.1 MCP 协议简介

Model Context Protocol (MCP) 是 Anthropic 提出的开放协议，用于：

  • 标准化 LLM 与外部工具的通信
  • 实现工具、资源、提示语的跨平台共享
  • 类似"AI 领域的 USB 接口"

7.1.2 MCP 核心概念

概念 说明
Tool 可调用的函数（如：查询天气、执行 SQL）
Resource 可访问的资源（如：文件、数据库记录）
Prompt 预定义的提示词模板
Transport 传输层（stdio / SSE / Streamable HTTP）

7.1.3 Solon-AI 的 MCP 实现

// 服务端：注解驱动
@McpServerEndpoint(channel = McpChannel.STREAMABLE, mcpEndpoint = "/mcp")
public class MyMcpServer {
    @ToolMapping(description = "查询天气")
    public String getWeather(@Param(description = "城市") String location) {
        return "晴，25度";
    }
}

// 客户端：Builder 模式
McpClientProvider client = McpClientProvider.builder()
        .channel(McpChannel.STREAMABLE)
        .url("http://localhost:8080/mcp")
        .build();

7.2 实践练习

练习1：MCP Server

import org.noear.solon.ai.mcp.*;
import org.noear.solon.ai.mcp.annotation.*;

@McpServerEndpoint(channel = McpChannel.STREAMABLE, mcpEndpoint = "/mcp")
public class CalculatorMcpServer {

    @ToolMapping(description = "加法运算")
    public String add(@Param(description = "第一个数") Double a, 
                      @Param(description = "第二个数") Double b) {
        return String.format("%.2f", a + b);
    }

    @ToolMapping(description = "乘法运算")
    public String multiply(@Param(description = "第一个数") Double a, 
                           @Param(description = "第二个数") Double b) {
        return String.format("%.2f", a * b);
    }
}

启动类：

public class McpServerApp {
    public static void main(String[] args) {
        Solon.start(McpServerApp.class, args);
    }
}

验证：

# 使用 MCP Inspector 测试
npx @modelcontextprotocol/inspector

# 或使用 curl
curl -X POST http://localhost:8080/mcp \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","method":"tools/call","params":{"name":"add","arguments":{"a":1,"b":2}}}'

练习2：MCP Client 集成到 Agent

public class McpAgentDemo {
    public static void main(String[] args) {
        ChatModel chatModel = ChatModel.of("http://127.0.0.1:11434/api/chat")
                .provider("ollama")
                .model("qwen2.5:1.5b")
                .build();

        // 1. 创建 MCP 客户端
        McpClientProvider mcpClient = McpClientProvider.builder()
                .channel(McpChannel.STREAMABLE)
                .url("http://localhost:8080/mcp")
                .build();

        // 2. 将 MCP 工具注入 Agent
        ReActAgent agent = ReActAgent.of(chatModel)
                .name("math_agent")
                .description("数学计算助手")
                .mcpToolsAdd(mcpClient)  // 自动加载远程工具
                .build();

        // 3. 自然语言调用远程工具
        String response = agent.prompt("帮我计算 123 乘以 456 等于多少？")
                .call()
                .getMessage()
                .getContent();

        System.out.println("AI: " + response);
    }
}

7.3 项目实战

实战任务：MCP 工具网关

实现一个 MCP 工具聚合网关，支持： - 注册多个 MCP Server - 统一鉴权（API Key） - 工具发现与自动调用 - 调用日志与监控

第7章 注意事项

  1. MCP 端点路径唯一性：@McpServerEndpoint 的 mcpEndpoint（如 /mcp）在应用内必须唯一，多个 Server 重复注册会启动失败。
  2. SSE 依赖：McpChannel.STREAMABLE 依赖 solon-web-sse，确保 pom 中已引入该模块，否则会报 NoClassDefFoundError。
  3. 参数描述即提示词：@Param(description = "...") 的内容会直接拼入工具描述传给 LLM，建议包含格式示例（如 "city": "北京"）。
  4. Client 连接稳定性：远程 MCP Server 可能因网络抖动断开，建议为 McpClientProvider 配置超时和重试策略。
  5. A2A 实验性质：solon-ai-mcp 中的 A2A（Agent-to-Agent）代码仍在实验室阶段，API 可能随时调整，不建议直接用于生产。

第7章 实战作业

作业1：基础巩固

独立部署一个 MCP Server（Solon），暴露两个工具： - get_weather(city)：返回模拟天气数据 - calculator(expression)：执行数学表达式 使用官方 @modelcontextprotocol/inspector 验证工具调用成功。

作业2：拓展应用

实现工具链组合场景： - MCP Server 暴露 get_city_coord(city) 和 weather_by_coord(lat, lon) - 构建一个 Agent，用户问"北京天气怎么样"时，Agent 自动先调用 get_city_coord，再调用 weather_by_coord

作业3：动手实践

实现一个简易 MCP 工具注册中心： - 支持动态注册 MCP Server（URL、名称、描述） - 提供统一入口 POST /api/mcp/tools/{serverName}/call - 记录每次工具调用的请求参数、返回结果、耗时到数据库 - 提供管理页面展示各 Server 的工具列表和最近调用记录
