4.1 理论讲解

4.1.1 工具是什么？

工具（Tool）是 让 LLM 具备外部能力 的机制，例如： - 查询天气 - 执行 SQL - 调用 API - 读写文件

Solon-AI 的工具模型：

ToolProvider.builder("tool_name")
    .description("工具描述")
    .param("param1", String.class, "参数说明", true)  // required
    .param("param2", Integer.class, "参数说明", false) // optional
    .executable(args -> {
        // 执行逻辑
        return result;
    })
    .build();

4.2 实践练习

练习1：天气查询工具

import org.noear.solon.ai.chat.tool.ToolProvider;
import org.noear.solon.ai.chat.tool.ToolExecutable;

public class WeatherToolDemo {

    static ToolProvider weatherTool = ToolProvider.of("get_weather")
            .description("获取指定城市的当前天气")
            .param("city", String.class, "城市名称，如：北京、上海", true)
            .param("unit", String.class, "温度单位：celsius/fahrenheit", false)
            .executable((ToolExecutable) args -> {
                String city = args.getString("city");
                String unit = args.optString("unit", "celsius");

                // 模拟天气数据
                double temp = 20 + Math.random() * 10;
                if ("fahrenheit".equals(unit)) {
                    temp = temp * 9 / 5 + 32;
                }

                return String.format("{\"city\":\"%s\",\"temp\":%.1f,\"unit\":\"%s\"}", 
                        city, temp, unit);
            });

    public static void main(String[] args) {
        ChatModel chatModel = ChatModel.of("http://127.0.0.1:11434/api/chat")
                .provider("ollama")
                .model("qwen2.5:1.5b")
                .build();

        String response = chatModel.prompt("北京今天天气怎么样？")
                .options(op -> op.toolAdd(weatherTool))
                .call()
                .getMessage()
                .getContent();

        System.out.println(response);
    }
}

练习2：计算器工具

static ToolProvider calculatorTool = ToolProvider.of("calculator")
        .description("执行基本的数学运算，支持加减乘除")
        .param("expression", String.class, "数学表达式，如：2+3*4", true)
        .executable((ToolExecutable) args -> {
            String expr = args.getString("expression");
            try {
                // 注意：生产环境应使用安全解析器，避免 ScriptEngine 的安全风险
                double result = new ScriptEngineManager()
                        .getEngineByName("javascript")
                        .eval(expr) instanceof Number n ? n.doubleValue() : 0;
                return String.format("%s = %.2f", expr, result);
            } catch (Exception e) {
                return "计算错误: " + e.getMessage();
            }
        });

4.3 项目实战

实战任务：智能助手工具集

实现一个包含 3 个工具的智能助手： 1. 当前时间工具：get_current_time 2. 简单计算器工具：calculator 3. 随机数生成器：random_number（支持指定范围）

第4章 注意事项

  1. ToolProvider 参数顺序：param(name, type, description, required) 第四个参数才是必填标志，顺序容易写错。
  2. 返回值类型：ToolExecutable 的返回值必须是 String 或可被 JSON 序列化的对象，否则 LLM 会收到乱码或解析失败。
  3. 描述即准确率：工具描述（description）和参数说明直接影响模型调用准确率，建议包含参数格式示例和返回格式说明。
  4. ScriptEngine 安全风险：ScriptEngineManager 在服务端暴露 eval 存在代码注入风险，生产环境应使用受限表达式解析器（如 exp4j、JEval）。
  5. 线程安全：LLM 可能并发调用同一工具，确保 ToolExecutable 实现是无状态或线程安全的，避免共享可变状态。

第4章 实战作业

作业1：基础巩固

实现一个 currency_converter 汇率转换工具，支持 USD、CNY、EUR 三种货币互转（使用固定汇率：1 USD = 7.2 CNY，1 EUR = 7.8 CNY）。

作业2：拓展应用

实现链式工具调用场景： - geocode(city)：将城市名转换为经纬度（模拟返回） - weather_by_coord(lat, lon)：根据经纬度查询天气 让 LLM 先调用 geocode，再根据返回结果调用 weather_by_coord。

作业3：动手实践

实现一个 file_tools 工具集，包含三个方法： - read_file(path)：读取本地文本文件，限制最大 100KB - write_file(path, content)：写入文件（覆盖模式） - append_file(path, content)：追加内容到文件末尾 要求：路径必须限制在 /tmp 目录下，防止目录遍历攻击。
