5.1.1 RAG 架构（五步法）

┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│ 文档加载  │ -> │ 文档切分  │ -> │ 向量化    │ -> │ 存储索引  │ -> │ 检索增强  │
│ Loader   │    │ Splitter │    │ Embedding│    │ Repository│   │ Retrieval│
└──────────┘    └──────────┘    └──────────┘    └──────────┘    └──────────┘

5.2 实践练习

练习1：InMemory 知识库（零依赖）

import org.noear.solon.ai.rag.*;
import org.noear.solon.ai.rag.loader.MarkdownLoader;
import org.noear.solon.ai.rag.splitter.RegexTextSplitter;

public class SimpleRAG {
    public static void main(String[] args) throws Exception {
        // 1. 构建 Embedding Model（使用 Ollama 本地 bge-m3）
        EmbeddingModel embeddingModel = EmbeddingModel.of("http://127.0.0.1:11434/api/embed")
                .provider("ollama")
                .model("bge-m3")
                .build();

        // 2. 创建内存知识库
        InMemoryRepository repository = new InMemoryRepository(embeddingModel);

        // 3. 加载并切分文档
        DocumentLoader loader = new MarkdownLoader(
                "https://solon.noear.org/article/about?format=md"
        );
        List<Document> documents = loader.load();

        // 4. 切分
        DocumentSplitter splitter = new RegexTextSplitter();
        List<Document> chunks = splitter.split(documents);

        // 5. 写入知识库
        repository.insert(chunks);

        // 6. 检索
        String query = "Solon 框架是谁开发的？";
        List<Document> results = repository.search(query, 3);

        // 7. 构造增强 Prompt
        ChatMessage augmentedMessage = ChatMessage.ofUserAugment(query, results);

        // 8. 调用 LLM
        ChatModel chatModel = ChatModel.of("http://127.0.0.1:11434/api/chat")
                .provider("ollama")
                .model("qwen2.5:1.5b")
                .build();

        String answer = chatModel.prompt(augmentedMessage)
                .system("你是一个知识库助手，请基于提供的上下文回答用户问题。"
                        + "如果上下文中没有答案，请明确告知。")
                .call()
                .getMessage()
                .getContent();

        System.out.println("AI: " + answer);
    }
}

练习2：PgVector 持久化知识库

import org.noear.solon.ai.rag.repository.pg.PgVectorRepository;

public class PgVectorRAG {
    public static void main(String[] args) throws Exception {
        // 1. Embedding Model
        EmbeddingModel embeddingModel = EmbeddingModel.of("http://127.0.0.1:11434/api/embed")
                .provider("ollama")
                .model("bge-m3")
                .build();

        // 2. PgVector Repository（需要 PostgreSQL + pgvector 扩展）
        PgVectorRepository repository = PgVectorRepository.builder(embeddingModel)
                .url("jdbc:postgresql://localhost:5432/rag_db")
                .username("postgres")
                .password("password")
                .table("knowledge_base")
                .build();

        // 3. 加载 PDF
        List<Document> documents = new PdfLoader("/path/to/file.pdf").load();

        // 4. 切分并写入
        repository.insert(new TokenSizeTextSplitter().split(documents));

        // 5. 检索
        List<Document> results = repository.search("什么是 RAG？", 5);

        results.forEach(doc -> {
            System.out.println("Score: " + doc.getScore());
            System.out.println("Content: " + doc.getText());
            System.out.println("---");
        });
    }
}

练习3：重排序（Reranking）

import org.noear.solon.ai.rag.rerank.RerankingModel;

public class RerankingDemo {
    public static void main(String[] args) {
        // 1. 初始检索（召回 Top 20）
        List<Document> candidates = repository.search(query, 20);

        // 2. Reranker 精排（BGE-Reranker）
        RerankingModel reranker = RerankingModel.of("http://127.0.0.1:11434/api/rerank")
                .provider("ollama")
                .model("bge-reranker-v2-m3")
                .build();

        // 3. 精排后取 Top 5
        List<Document> finalResults = reranker.rerank(query, candidates, 5);

        // 4. 增强 Prompt
        ChatMessage message = ChatMessage.ofUserAugment(query, finalResults);
    }
}

5.3 项目实战

实战任务：企业文档智能问答系统

实现一个支持多格式文档的 RAG 系统：

  • 文档管理：上传 PDF/Word/Excel/Markdown
  • 自动切分：支持固定长度 + 重叠滑动窗口
  • 向量化：使用 bge-m3（本地 Ollama）
  • 持久化：PgVector 存储
  • 检索增强：Hybrid Search（向量 + 关键词）+ Rerank
  • 对话接口：REST API 暴露

技术栈： - Solon-AI（RAG 全链路） - PostgreSQL + pgvector（向量存储） - Ollama（bge-m3 嵌入模型） - Solon Web（REST API）

第5章 注意事项

  1. 文档切分粒度：chunk 过短会丢失语义，过长会稀释检索精度。推荐起始值：500-1000 token，重叠率 10%-20%。
  2. InMemoryRepository 仅用于原型：数据完全存在内存，应用重启即丢失，严禁用于生产。
  3. 嵌入 ≠ 重排序：EmbeddingModel 用于向量化，RerankingModel 用于精排，二者模型不同、API 不同，不可混用。
  4. PgVector 环境要求：需要 PostgreSQL 15+ 且已安装 pgvector 扩展，建表时列类型必须为 vector(维度)，否则插入会报错。
  5. 向量检索不稳定性：相同 query 多次检索结果可能不一致（尤其是 topK 边界），生产环境建议必配 Rerank 提升结果稳定性。

第5章 实战作业

作业1：基础巩固

使用 MarkdownLoader 加载一篇 Solon 官方文档（如 https://solon.noear.org/article/about?format=md），构建 InMemoryRepository，执行 3 个不同 query 并输出检索结果及相似度分数。

作业2：拓展应用

实现 Hybrid Search（混合检索）： - 向量检索：召回 Top 20 - 关键词检索：使用 solon-ai-talent-lucene 模块 - 融合策略：Reciprocal Rank Fusion (RRF) - 最终取 Top 5 并做 Rerank

作业3：动手实践

构建一个文件上传 Web 服务： - POST /api/document/upload：支持 PDF/Markdown/Word - 上传后自动：切分（TokenSizeTextSplitter）→ 向量化（bge-m3）→ 存入 PgVectorRepository - GET /api/document/search?q=xxx：执行检索并返回 Top 5 结果（含原文片段、分数、来源文件）
