18.1 理论讲解

18.1.1 GIS 空间智能的价值

行业痛点： 1. 空间数据孤岛：地图数据、POI 数据、遥感数据分散在不同系统 2. 查询门槛高：需要学习 GIS 专业知识（空间关系、坐标系转换） 3. 分析深度有限：传统 GIS 工具侧重于可视化，缺乏智能分析 4. 多模态融合难：视频 + 空间 + 文本难以统一分析

AI 赋能 GIS 的三个层次： 1. 辅助层：自然语言查询空间数据（"查找所有靠近水源的监控点"） 2. 智能层：空间关系推理、路径规划、选址分析 3. 决策层：区域态势评估、资源调度优化

18.1.2 核心技术

1. 空间数据索引

  • R-tree / Quad-tree 空间索引
  • GeoHash / S2 Geometry 空间编码
  • 距离计算（欧氏距离、曼哈顿距离、球面距离）

2. 空间语义检索

  • 结合文本描述 + 空间位置
  • 例如："朝阳区附近的咖啡店" → 文本匹配 "咖啡店" + 空间范围 "朝阳区"

3. 空间关系推理

  • 包含（Contains）、相交（Intersects）、相邻（Adjacent）
  • 基于 LLM 的空间关系理解

4. 多模态融合

  • 视频帧 + 空间坐标 + 文本描述
  • 遥感图像 + 地面传感器数据

18.1.4 关键技术决策

Q1：空间数据库选型

方案 优点 缺点 适用场景
PostGIS 功能完善、生态好 性能一般 中小规模
MongoDB + GeoJSON 灵活、易用 空间索引弱 原型开发
Elasticsearch 全文 + 空间结合 复杂查询弱 搜索场景
GeoMesa 分布式、大规模 学习成本高 大规模时空数据

推荐：PostGIS（功能完善，适合大多数场景）

Q2：前端地图引擎选型

引擎 优点 缺点 适用场景
Cesium 3D 能力、开源 学习成本高 三维可视化
Mapbox GL JS 性能好、样式美 商业授权 二维地图
高德/百度地图 API 国内数据全 依赖第三方 国内应用
天地图 国产、合规 功能有限 信创项目

推荐：Cesium（3D 能力 + 开源，适合复杂场景）

Q3：空间数据存储策略

数据类型 存储方案
矢量数据（POI/行政区） PostGIS
栅格数据（遥感影像） COG + CDN
轨迹数据 TDEngine（时序） + PostGIS
实时位置 Redis Geo

练习1：空间数据 CRUD

目标：使用 PostGIS 管理空间数据

@Singleton
public class SpatialDataService {
    private final SpatialRepository repository;

    public void createPointOfInterest(String name, double lng, double lat, String category) {
        // 1. 构造空间对象
        Geometry point = GeometryFactory.createPoint(lng, lat);

        // 2. 创建 POI
        POI poi = new POI();
        poi.setName(name);
        poi.setCategory(category);
        poi.setLocation(point);
        poi.setCreatedAt(System.currentTimeMillis());

        // 3. 存储（PostGIS 自动建立空间索引）
        repository.save(poi);
    }

    public List<POI> searchWithin(String wktPolygon) {
        // 1. 解析多边形
        Geometry polygon = WKTReader.read(wktPolygon);

        // 2. 空间查询（使用 R-tree 索引）
        return repository.findWithin(polygon);
    }
}

练习2：空间语义检索

目标：结合文本 + 空间位置进行检索

@Singleton
public class SpatialSemanticSearch {
    private final SpatialRepository spatialRepo;
    private final ElasticsearchClient esClient;
    private final EmbeddingModel embeddingModel;

    public List<POI> search(String query, BoundingBox bbox) {
        // 1. 文本语义检索
        Embedding queryEmbedding = embeddingModel.embed(query);
        List<POI> textResults = esClient.search(query, bbox);

        // 2. 空间范围过滤
        List<POI> spatialResults = spatialRepo.findWithin(bbox.toPolygon());

        // 3. 融合排序
        return mergeResults(textResults, spatialResults);
    }
}

public class SpatialAgent {
    private final McpClientProvider mcpClient;
    private final ChatModel chatModel;

    public RoutePlanResult planRoute(String start, String end, List<String> waypoints) {
        // 1. 构造 Prompt
        String prompt = String.format("""
            规划从 %s 到 %s 的路径，途经点：%s

            约束条件：
            - 避开拥堵路段
            - 避开限行区域
            - 优先选择充电桩多的路线（如果是电动车）
            """, start, end, String.join(", ", waypoints));

        // 2. 调用 LLM 生成路径规划请求
        ChatResponse response = chatModel.prompt(prompt)
                .system("你是路径规划专家")
                .call();

        // 3. 调用地图 API（通过 MCP）
        McpClient mapClient = mcpClient.create("map-service");
        Map<String, Object> route = mapClient.callTool("plan_route", Map.of(
            "start", start,
            "end", end,
            "waypoints", waypoints
        ));

        return RoutePlanResult.fromMap(route);
    }
}

模块1：空间数据管理服务

@Singleton
public class SpatialDataService {
    private final SpatialRepository repository;
    private final FileStorage fileStorage;

    public void importShapefile(MultipartFile file) throws Exception {
        // 1. 解析 Shapefile
        ShapefileReader reader = new ShapefileReader(file.getInputStream());
        List<Feature> features = reader.readAll();

        // 2. 转换为 PostGIS 格式
        List<SpatialEntity> entities = features.stream()
                .map(feature -> SpatialEntity.builder()
                        .name(feature.getString("name"))
                        .category(feature.getString("category"))
                        .geometry(feature.getGeometry())
                        .properties(feature.getAttributes())
                        .build())
                .toList();

        // 3. 批量导入
        repository.batchSave(entities);
    }

    public List<SpatialEntity> spatialQuery(String wkt, String operation) {
        Geometry geometry = WKTReader.read(wkt);

        return switch (operation) {
            case "within" -> repository.findWithin(geometry);
            case "intersects" -> repository.findIntersects(geometry);
            case "contains" -> repository.findContains(geometry);
            case "nearby" -> repository.findNearby(geometry, 1000); // 1km
            default -> throw new IllegalArgumentException("Unsupported operation: " + operation);
        };
    }
}

模块3：Agent 空间分析

@Singleton
public class SpatialAnalysisAgent {
    private final McpClientProvider mcpClient;
    private final ChatModel chatModel;

    public SpatialAnalysisResult analyze(String query) {
        // 1. 解析用户意图
        Intent intent = parseIntent(query);

        // 2. 调用空间分析工具
        McpClient spatialClient = mcpClient.create("spatial-service");

        Map<String, Object> analysisResult = switch (intent.getType()) {
            case "DISTRIBUTION" -> spatialClient.callTool("analyze_distribution", 
                Map.of("area", intent.getArea(), "category", intent.getCategory()));
            case "DENSITY" -> spatialClient.callTool("analyze_density",
                Map.of("area", intent.getArea(), "metric", intent.getMetric()));
            case "TREND" -> spatialClient.callTool("analyze_trend",
                Map.of("timeRange", intent.getTimeRange()));
            default -> throw new UnsupportedIntentException(intent.getType());
        };

        // 3. 生成自然语言报告
        String report = generateReport(analysisResult, query);

        return SpatialAnalysisResult.builder()
                .result(analysisResult)
                .report(report)
                .build();
    }

    private Intent parseIntent(String query) {
        ChatResponse response = chatModel.prompt(query)
                .system("你是空间分析专家，解析用户的空间分析意图")
                .call();
        return Intent.fromJson(response.getMessage().getContent());
    }
}

@RestController
@RequestMapping("/api/spatial")
public class SpatialDataController {
    private final SpatialDataService spatialDataService;

    @Get("/query")
    public List<SpatialEntity> query(
            @Param("wkt") String wkt,
            @Param("operation") String operation,

    @Get("/search")
    public List<ScoredSpatialEntity> semanticSearch(
            @Param("q") String query,
            @Param("bbox") String bbox) {

    @Post("/import")
    public Result importShapefile(@Body MultipartFile file) {

            spatialDataService.importShapefile(file);

            return Result.fail("导入失败: " + e.getMessage());
        }
    }
}

第四阶段总结与学习建议

18.4 注意事项

  1. 坐标系转换：国内使用 GCJ-02（火星坐标），境外使用 WGS-84，转换时注意精度损失
  2. 空间索引优化：PostGIS 的 GIST 索引对查询性能至关重要，大批量导入后需 VACUUM ANALYZE
  3. Cesium 资源加载：3D 地形和影像数据量大，需使用 CDN 加速，避免首次加载过慢
  4. 空间查询性能：复杂空间运算（如缓冲区分析）消耗 CPU，建议异步处理 + 缓存结果
  5. 多模态数据对齐：视频帧与空间坐标的时间同步是关键，需使用 NTP 或 PTP 协议
