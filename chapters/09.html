9.1 理论讲解

9.1.1 Talent 设计理念

Talent = 领域能力 + 工具集 + 准入规则 + 动态指令

Talent talent = new TalentDesc("order_expert")
        .description("订单助手")
        // 动态准入：只有提到"订单"时才激活
        .isSupported(prompt -> prompt.getUserMessageContent().contains("订单"))
        // 动态指令：根据用户等级注入不同 SOP
        .instruction(prompt -> {
            if ("VIP".equals(prompt.getMeta("user_level"))) {
                return "这是尊贵的 VIP 客户，请优先调用 fast_track_tool。";
            }
            return "按常规流程处理订单查询。";
        })
        .toolAdd(new OrderTools());

9.2 实践练习

练习1：自定义 Talent

Talent hrTalent = new TalentDesc("hr_assistant")
        .description("HR 助手")
        .isSupported(prompt -> 
            prompt.getUserMessageContent().contains("请假") ||
            prompt.getUserMessageContent().contains("离职") ||
            prompt.getUserMessageContent().contains("入职")
        )
        .instruction(prompt -> "你是一位 HR 助手，请根据公司政策回答员工问题。")
        .toolAdd(new LeaveQueryTool())
        .toolAdd(new PolicyQueryTool());

chatModel.prompt("我想请假 3 天")
        .options(op -> op.talentAdd(hrTalent))
        .call();

9.3 项目实战

实战任务：企业知识助手

结合 Talent + RAG + Agent，实现： - memory Talent：记忆员工信息 - pdf Talent：解析员工手册 - mail Talent：发送通知邮件 - lucene Talent：全文检索政策文档

第9章 注意事项

  1. isSupported 动态评估：TalentDesc.isSupported() 在每次用户输入时都会执行，不要在内部写高开销逻辑，避免影响响应速度。
  2. instruction 长度控制：动态指令返回的字符串建议控制在 500 字以内，过长会挤占模型推理空间，且可能超出上下文窗口。
  3. Talent 依赖显式引入：预置 Talent（如 pdf、mail）需要单独引入对应模块，仅引入 solon-ai-talents 不会自动加载全部 Talent。
  4. 描述合并机制：Talent 内部调用工具时，Talent 描述与工具描述会合并传给 LLM，注意总长度是否超出模型限制。
  5. 调试技巧：使用 System.out.println("talent supported: " + talent.isSupported(prompt)) 打印准入结果，确认 instruction 动态生成符合预期。

第9章 实战作业

作业1：基础巩固

自定义一个 leave_assistant Talent，处理以下场景： - 查询年假剩余天数 - 请假流程说明 - 加班调休规则 要求：isSupported 匹配"请假/年假/调休/加班"关键词。

作业2：拓展应用

实现 Talent 的上下文感知能力： - 从 prompt.getMeta("department") 获取用户部门 - 技术部：返回弹性工作制政策 - 市场部：返回固定考勤政策 - 未识别部门：返回通用政策

作业3：动手实践

组合 memory + pdf + mail 三个 Talent，实现"新员工入职流程自动化"： 1. memory Talent：记录新员工姓名、部门、岗位 2. pdf Talent：解析《员工手册.pdf》，提取相关章节 3. mail Talent：发送欢迎邮件（含部门政策摘要） 用户输入"我要入职"时，自动触发完整流程。
