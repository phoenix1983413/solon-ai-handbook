16.1 理论讲解

16.1.1 数据智能化的核心价值

行业痛点： - 业务人员不会写 SQL，依赖数据团队，响应周期长 - 报表需求多，数据团队成为瓶颈 - 数据孤岛，跨库关联分析困难 - 决策缺乏数据支撑，拍脑袋多

AI 赋能数据分析的三个层次： 1. 辅助层：SQL 生成、报表自动化 2. 智能层：异常检测、趋势预测、关联分析 3. 决策层：自动生成洞察报告、决策建议

16.1.2 Text2SQL 技术演进

规则引擎时代（Template-based） - 基于预定义模板匹配 - 优点：准确率高、可控性强 - 缺点：覆盖场景有限、维护成本高

小模型微调时代（T5/LLaMA） - 在领域数据上微调小模型 - 优点：成本低、响应快 - 缺点：复杂查询准确率低

大模型时代（GPT-4/Claude/Qwen） - 基于 Schema 描述 + Few-shot - 优点：理解能力强、覆盖场景广 - 缺点：成本高、需要提示工程

Solon-AI 方案： - 结合大模型 + Schema 描述 + 验证器 - 生成 SQL 后通过 Apache Calcite 验证语法 - 敏感操作拦截（DROP/DELETE/UPDATE）

16.1.4 关键技术决策

Q1：Schema 描述策略

策略 优点 缺点 适用场景
DDL 原文 准确、完整 冗长、含噪声 技术用户
自然语言描述 简洁、易读 可能遗漏细节 业务用户
混合（DDL + 注释） 兼顾准确和易读 维护成本高 企业级

推荐：混合策略 - DDL 为主，关键字段附加自然语言注释

Q2：SQL 安全审查

风险操作 审查策略
DROP TABLE/DATABASE 禁止
DELETE/UPDATE 无 WHERE 禁止
跨库 JOIN 限制数据源
全表扫描 告警 + 限制

推荐：使用 Apache Calcite 解析 SQL，实现语法验证和安全审查

Q3：结果缓存策略

场景 缓存策略 TTL
相同查询 缓存完整结果 5 分钟
相似查询 缓存 Schema + 计划 1 小时
元数据查询 缓存表结构 24 小时

16.2 实践练习

练习1：基于 Schema 的 Text2SQL

目标：实现自然语言转 SQL

@Singleton
public class Text2SqlEngine {
    private final ChatModel chatModel;
    private final SchemaManager schemaManager;
    private final SqlValidator validator;

    public String generateSql(String naturalLanguage, DataSource dataSource) {
        // 1. 获取 Schema 描述
        String schemaDescription = schemaManager.getDescription(dataSource);

        // 2. 构造 Prompt
        String prompt = String.format("""
            你是一个 SQL 专家。根据以下数据库 Schema，将自然语言查询转为 SQL。

            Schema:
            %s

            要求：
            1. 只使用 SELECT 语句，禁止 DROP/DELETE/UPDATE
            2. 使用标准 SQL 语法
            3. 包含 LIMIT 1000 防止全表扫描
            4. 只输出 SQL，不要解释

            查询：%s
            """, schemaDescription, naturalLanguage);

        // 3. 调用 LLM
        ChatResponse response = chatModel.prompt(prompt).call();
        String sql = response.getMessage().getContent();

        // 4. 验证 SQL
        ValidationResult result = validator.validate(sql, dataSource);
        if (!result.isValid()) {
            throw new SqlGenerationException("Invalid SQL: " + result.getErrorMessage());
        }

        return sql;
    }
}

关键工程细节： - Schema 描述需要精简（只包含表名、字段名、类型、注释） - 使用 Apache Calcite 做语法验证 - 敏感操作拦截（正则匹配 DROP/DELETE/UPDATE）

练习2：SQL 安全审查器

@Singleton
public class SqlSecurityReviewer {
    private static final Pattern DANGEROUS_PATTERN = 
        Pattern.compile("(?i)(DROP|DELETE|UPDATE|TRUNCATE|ALTER)\\s+(TABLE|DATABASE|INDEX)");

    public SecurityReviewResult review(String sql) {
        List<String> violations = new ArrayList<>();

        // 1. 检查危险操作
        Matcher matcher = DANGEROUS_PATTERN.matcher(sql);
        while (matcher.find()) {
            violations.add("检测到危险操作: " + matcher.group());
        }

        // 2. 检查是否带 WHERE 的 DELETE/UPDATE
        if (sql.matches("(?i).*\\bDELETE\\b.*\\bFROM\\b(?!.*\\bWHERE\\b).*")) {
            violations.add("DELETE 语句缺少 WHERE 条件");
        }

        // 3. 检查全表扫描
        if (!sql.contains("LIMIT") && !sql.matches("(?i).*\\bWHERE\\b.*")) {
            violations.add("查询缺少 WHERE 条件，可能导致全表扫描");
        }

        return SecurityReviewResult.builder()
                .safe(violations.isEmpty())
                .violations(violations)
                .build();
    }
}

练习3：数据血缘追踪

@Singleton
public class DataLineageTracker {
    private final FlowEngine flowEngine;

    public LineageGraph buildLineage(String tableName) {
        // 1. 查找所有引用该表的 ETL Flow
        List<FlowDefinition> upstreamFlows = flowEngine.findUpstream(tableName);

        // 2. 查找所有使用该表的报表/查询
        List<QueryRecord> downstreamQueries = queryLogRepository.findByTable(tableName);

        // 3. 构建血缘图
        LineageGraph graph = new LineageGraph(tableName);

        for (FlowDefinition flow : upstreamFlows) {
            graph.addUpstream(flow.getSourceTable(), flow.getTransformation());
        }

        for (QueryRecord query : downstreamQueries) {
            graph.addDownstream(query.getQueryId(), query.getQueryType());
        }

        return graph;
    }
}

练习4：智能报表生成

@Singleton
public class SmartReportGenerator {
    private final Text2SqlEngine text2SqlEngine;
    private final ChartGenerator chartGenerator;

    public Report generate(String topic, DateRange range) {
        // 1. 使用 LLM 分解报告需求
        List<ReportSection> sections = planReport(topic);

        // 2. 逐节生成
        List<ReportSectionResult> results = new ArrayList<>();
        for (ReportSection section : sections) {
            // 2.1 生成 SQL
            String sql = text2SqlEngine.generateSql(section.getQuery(), section.getDataSource());

            // 2.2 执行查询
            QueryResult data = jdbcTemplate.query(sql);

            // 2.3 生成图表
            Chart chart = chartGenerator.generate(data, section.getChartType());

            results.add(ReportSectionResult.builder()
                    .title(section.getTitle())
                    .data(data)
                    .chart(chart)
                    .insight(generateInsight(data, section.getInsightPrompt()))
                    .build());
        }

        return Report.builder()
                .title(topic)
                .range(range)
                .sections(results)
                .build();
    }

    private String generateInsight(QueryResult data, String prompt) {
        ChatResponse response = chatModel.prompt(prompt)
                .system("你是数据分析专家，请分析以下数据并给出洞察")
                .call();
        return response.getMessage().getContent();
    }
}

模块1：元数据管理服务

@Singleton
public class SchemaManager {
    private final DataSourceMetadataRepository repository;

    public String getDescription(DataSource dataSource) {
        // 1. 获取所有表
        List<TableMetadata> tables = repository.getTables(dataSource);

        // 2. 获取所有字段
        List<ColumnMetadata> columns = repository.getColumns(dataSource);

        // 3. 构建 Schema 描述
        StringBuilder sb = new StringBuilder();
        for (TableMetadata table : tables) {
            sb.append("表 ").append(table.getName()).append(": ").append(table.getComment()).append("\n");

            List<ColumnMetadata> tableColumns = columns.stream()
                    .filter(c -> c.getTableName().equals(table.getName()))
                    .toList();

            for (ColumnMetadata col : tableColumns) {
                sb.append("  - ").append(col.getName())
                  .append(" (").append(col.getType()).append(")")
                  .append(": ").append(col.getComment()).append("\n");
            }
            sb.append("\n");
        }

        return sb.toString();
    }
}

模块2：Text2SQL 引擎

@Singleton
public class Text2SqlEngine {
    private final ChatModel chatModel;
    private final SchemaManager schemaManager;
    private final SqlSecurityReviewer securityReviewer;

    public SqlGenerationResult generate(String naturalLanguage, DataSource dataSource) {
        // 1. 获取 Schema
        String schema = schemaManager.getDescription(dataSource);

        // 2. 构造 Prompt
        String prompt = buildPrompt(naturalLanguage, schema);

        // 3. 调用 LLM
        ChatResponse response = chatModel.prompt(prompt).call();
        String sql = extractSql(response.getMessage().getContent());

        // 4. 安全审查
        SecurityReviewResult review = securityReviewer.review(sql);
        if (!review.isSafe()) {
            return SqlGenerationResult.fail("SQL 不安全: " + review.getViolations());
        }

        // 5. 语法验证（可选）
        ValidationResult validation = validator.validate(sql, dataSource);
        if (!validation.isValid()) {
            return SqlGenerationResult.fail("SQL 语法错误: " + validation.getErrorMessage());
        }

        return SqlGenerationResult.success(sql);
    }

    private String buildPrompt(String query, String schema) {
        return String.format("""
            你是一个 SQL 专家。根据以下数据库 Schema，将自然语言查询转为 SQL。

            Schema:
            %s

            要求：
            1. 只使用 SELECT 语句，禁止 DROP/DELETE/UPDATE
            2. 使用标准 SQL 语法
            3. 包含 LIMIT 1000 防止全表扫描
            4. 只输出 SQL，不要解释

            查询：%s
            """, schema, query);
    }
}

模块3：SQL 安全审查器

@Singleton
public class SqlSecurityReviewer {
    private static final Pattern DANGEROUS_PATTERN = 
        Pattern.compile("(?i)(DROP|DELETE|UPDATE|TRUNCATE|ALTER)\\s+(TABLE|DATABASE|INDEX)");
    private static final Pattern DELETE_WITHOUT_WHERE = 
        Pattern.compile("(?i)\\bDELETE\\b.*\\bFROM\\b(?!.*\\bWHERE\\b)");

    public SecurityReviewResult review(String sql) {
        List<String> violations = new ArrayList<>();

        // 1. 检查危险操作
        Matcher matcher = DANGEROUS_PATTERN.matcher(sql);
        while (matcher.find()) {
            violations.add("检测到危险操作: " + matcher.group());
        }

        // 2. 检查 DELETE 是否有 WHERE
        if (DELETE_WITHOUT_WHERE.matcher(sql).find()) {
            violations.add("DELETE 语句缺少 WHERE 条件");
        }

        // 3. 检查全表扫描
        if (!sql.contains("LIMIT") && !sql.toLowerCase().contains("where")) {
            violations.add("查询缺少 WHERE 条件，可能导致全表扫描");
        }

        return SecurityReviewResult.builder()
                .safe(violations.isEmpty())
                .violations(violations)
                .build();
    }
}

模块4：查询结果可视化

@Singleton
public class QueryResultVisualizer {
    private final ChartGenerator chartGenerator;

    public VisualizationResult visualize(QueryResult result, String preferredChart) {
        // 1. 自动推荐图表类型
        String chartType = preferredChart != null ? preferredChart : recommendChartType(result);

        // 2. 生成图表配置
        Chart chart = chartGenerator.generate(result, chartType);

        // 3. 生成数据摘要
        String summary = generateSummary(result);

        return VisualizationResult.builder()
                .chart(chart)
                .summary(summary)
                .data(result)
                .build();
    }

    private String recommendChartType(QueryResult result) {
        // 根据数据特征推荐图表
        if (result.getColumns().size() == 2 && result.getRows().size() > 10) {
            return "line"; // 时序数据
        } else if (result.getColumns().size() == 2 && result.getRows().size() <= 10) {
            return "pie"; // 占比数据
        } else {
            return "table"; // 明细数据
        }
    }
}

模块5：数据血缘追踪

@Singleton
public class DataLineageService {
    private final EtlFlowRepository flowRepository;
    private final QueryLogRepository queryLogRepository;

    public LineageGraph buildLineage(String tableName) {
        LineageGraph graph = new LineageGraph(tableName);

        // 1. 上游 ETL（表级依赖）
        List<EtlFlow> upstreamFlows = flowRepository.findByTargetTable(tableName);
        for (EtlFlow flow : upstreamFlows) {
            graph.addUpstream(flow.getSourceTables(), flow.getTransformation());
        }

        // 2. 下游查询（谁在用这个表）
        List<QueryLog> downstreamQueries = queryLogRepository.findByTable(tableName);
        for (QueryLog log : downstreamQueries) {
            graph.addDownstream(log.getQueryId(), log.getQueryType());
        }

        return graph;
    }
}

@Singleton
public class SqlAuditInterceptor implements HandlerInterceptor {
    @Override
    public boolean beforeHandle(Invocation inv) {
        if (inv.getMethod().getName().equals("executeQuery")) {
            String sql = inv.getArgument(0);
            User user = SecurityContext.getCurrentUser();

            log.info("SQL executed: user={}, sql={}", user.getId(), sql);

            // 记录审计日志
            auditLogRepository.save(new SqlAuditLog(user.getId(), sql, System.currentTimeMillis()));
        }
        return true;
    }
}

慢查询优化与告警

@Singleton
public class SlowQueryMonitor {
    private static final Duration SLOW_QUERY_THRESHOLD = Duration.ofSeconds(3);

    @Subscribe
    public void onQueryCompleted(QueryCompletedEvent event) {
        if (event.getDuration().compareTo(SLOW_QUERY_THRESHOLD) > 0) {
            log.warn("Slow query detected: sql={}, duration={}ms", 
                event.getSql(), event.getDuration().toMillis());

            // 发送告警
            alertService.send("慢查询告警", event);
        }
    }
}
