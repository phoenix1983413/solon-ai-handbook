6.1 理论讲解

6.1.1 Agent 是什么？

Agent = LLM + 工具 + 记忆 + 规划

┌─────────────────────────────────────────┐
│              Agent 核心循环               │
│                                         │
│  1. 感知（Perceive）                     │
│     - 接收用户输入                       │
│     - 检索相关记忆                       │
│                                         │
│  2. 推理（Reason）                       │
│     - 分析当前状态                       │
│     - 决定下一步动作                     │
│                                         │
│  3. 行动（Act）                          │
│     - 调用工具                           │
│     - 执行外部操作                       │
│                                         │
│  4. 观察（Observe）                      │
│     - 收集工具返回结果                   │
│     - 更新记忆                           │
│                                         │
│  5. 回到 2，直到任务完成                  │
└─────────────────────────────────────────┘

6.1.2 ReAct 模式

ReAct = Reasoning（推理） + Acting（行动）

思考：我需要查询北京天气
行动：调用 get_weather(city="北京")
观察：北京今天 25°C，晴
思考：根据天气，我应该建议用户穿轻薄衣物
行动：生成最终回答

6.1.3 Team Agent 协作协议

Solon-AI 提供 6 种预置协议：

协议 说明 适用场景
HIERARCHICAL 层级式（Supervisor → Workers） 复杂任务分解
SEQUENTIAL 顺序式（流水线） 多阶段处理
CONTRACT_NET 合同网协议（招标-投标-中标） 任务分发
BLACKBOARD 黑板式（共享黑板） 数据汇聚分析
RESILIENCE 弹性式（故障转移） 高可用场景
CRITICAL_FIX 关键修复式（快速响应） 应急处理

6.2 实践练习

练习1：ReAct Agent

import org.noear.solon.ai.agent.*;
import org.noear.solon.ai.agent.react.*;

public class ReActAgentDemo {
    public static void main(String[] args) {
        ChatModel chatModel = ChatModel.of("http://127.0.0.1:11434/api/chat")
                .provider("ollama")
                .model("qwen2.5:1.5b")
                .build();

        // 创建 ReAct Agent
        ReActAgent agent = ReActAgent.of(chatModel)
                .name("weather_agent")
                .description("天气查询助手")
                .defaultToolAdd(WeatherToolDemo.weatherTool)  // 注入工具
                .build();

        // 自动完成：思考 -> 调用工具 -> 观察 -> 总结
        String response = agent.prompt("北京今天适合穿什么？")
                .call()
                .getMessage()
                .getContent();

        System.out.println("AI: " + response);
    }
}

练习2：Team Agent（层级式）

import org.noear.solon.ai.agent.team.*;

public class TeamAgentDemo {
    public static void main(String[] args) {
        ChatModel chatModel = ChatModel.of("http://127.0.0.1:11434/api/chat")
                .provider("ollama")
                .model("qwen2.5:1.5b")
                .build();

        // 1. 创建子 Agent（文案专家）
        Agent copywriter = Agent.create(chatModel, "copywriter")
                .description("文案撰写专家")
                .toolAdd(new CopywritingTools())
                .build();

        // 2. 创建子 Agent（视觉专家）
        Agent illustrator = Agent.create(chatModel, "illustrator")
                .description("视觉设计专家")
                .toolAdd(new ImageGenerationTools())
                .build();

        // 3. 创建 Team Agent（Supervisor）
        TeamAgent team = TeamAgent.of(chatModel)
                .name("marketing_team")
                .description("营销团队")
                .protocol(TeamProtocols.HIERARCHICAL)  // 层级式
                .agentAdd(copywriter)
                .agentAdd(illustrator)
                .build();

        // 4. 提交任务（Supervisor 自动分解并分发）
        String result = team.prompt("为深海矿泉水策划推广方案")
                .call()
                .getMessage()
                .getContent();

        System.out.println("团队产出: " + result);
    }
}

6.3 项目实战

实战任务：智能代码审查助手

实现一个基于 Agent 的代码审查系统：

  • Agent 1（静态分析）：检查代码风格、复杂度
  • Agent 2（安全扫描）：检测 SQL 注入、XSS 等漏洞
  • Agent 3（性能分析）：识别性能瓶颈
  • Supervisor：汇总报告，给出修复建议

核心代码：

public class CodeReviewSystem {
    public static void main(String[] args) {
        ChatModel chatModel = ChatModel.of("http://127.0.0.1:11434/api/chat")
                .provider("ollama")
                .model("qwen2.5:1.5b")
                .build();

        // 创建审查 Agent
        Agent styleAgent = Agent.create(chatModel, "style_checker")
                .description("代码风格检查员")
                .defaultToolAdd(new CodeStyleTool())
                .build();

        Agent securityAgent = Agent.create(chatModel, "security_scanner")
                .description("安全漏洞扫描员")
                .defaultToolAdd(new SecurityScanTool())
                .build();

        Agent perfAgent = Agent.create(chatModel, "performance_analyzer")
                .description("性能分析员")
                .defaultToolAdd(new PerfAnalyzeTool())
                .build();

        // 创建 Team
        TeamAgent reviewTeam = TeamAgent.of(chatModel)
                .name("code_review_team")
                .protocol(TeamProtocols.SEQUENTIAL)
                .agentAdd(styleAgent)
                .agentAdd(securityAgent)
                .agentAdd(perfAgent)
                .build();

        // 提交代码审查
        String code = Files.readString(Path.of("UserService.java"));
        String report = reviewTeam.prompt("请审查以下 Java 代码：\n" + code)
                .call()
                .getMessage()
                .getContent();

        System.out.println(report);
    }
}

第6章 注意事项

  1. 工具追加非覆盖：defaultToolAdd() 与 options(op -> op.toolAdd()) 是追加关系，同一 Agent 中多次添加会累积，注意避免重复注册同名工具。
  2. protocol 不可变：TeamAgent 的 protocol 一旦 build() 后不可更改，创建时需谨慎选择，调试阶段建议先用 SEQUENTIAL。
  3. Supervisor 汇总模式：默认 HIERARCHICAL 协议下，子 Agent 的执行结果由 Supervisor 汇总整理后返回，不会直接透传原始输出。
  4. 协议选择建议：HIERARCHICAL 最通用；BLACKBOARD 和 CONTRACT_NET 调试成本高，建议在掌握基础后再深入。
  5. TeamAgent 调试策略：先拆分为独立 Agent 单测通过，再组合为 Team；遇到异常时先关闭 Human-in-the-Loop，确认逻辑正确后再开启。

第6章 实战作业

作业1：基础巩固

构建一个"数学 tutors Team"： - Agent 1（出题员）：根据年级和知识点生成练习题 - Agent 2（批改员）：检查答案并给出评分和解析 使用 SEQUENTIAL 协议，实现"出题 → 作答 → 批改"流水线。

作业2：拓展应用

使用 HIERARCHICAL 协议实现"内容创作团队"： - Supervisor：接收任务"写一篇关于 RAG 的技术博客" - Worker 1（调研员）：搜索 RAG 最新进展和案例 - Worker 2（撰稿人）：根据调研结果撰写初稿 - Worker 3（编辑）：润色、排版、生成标题

作业3：动手实践

实现一个带 Human-in-the-Loop 的合同审批 Agent： - Agent 自动分析合同风险等级（低/中/高） - 当风险等级为"高"时，触发人工审批流程 - 用户可通过控制台输入"批准"/"驳回"及修改意见 - Agent 根据审批结果生成最终合同修订建议
