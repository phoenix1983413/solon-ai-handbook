8.1 理论讲解

8.1.1 什么是 AI Flow？

AI Flow 是 YAML 驱动的低代码编排引擎，将复杂的 AI 应用流程配置化：

id: customer_service_flow
layout:
  - type: "start"
  - task: "@VarInput"
    meta:
      message: "请输入您的问题"
  - task: "@EmbeddingModel"
    meta:
      provider: "ollama"
      model: "bge-m3"
  - task: "@InMemoryRepository"
    meta:
      query: "${input}"
      topK: 5
  - task: "@ChatModel"
    meta:
      systemPrompt: "你是一个客服助手"
      provider: "ollama"
      model: "qwen2.5:1.5b"
  - task: "@ConsoleOutput"

8.1.2 内置组件

组件 说明 示例
@VarInput 变量输入 用户输入
@EmbeddingModel 向量化 文本嵌入
@InMemoryRepository 内存知识库检索 RAG 检索
@ChatModel 模型调用 LLM 生成
@ConsoleOutput 控制台输出 结果展示

8.2 实践练习

练习1：简单 QA Flow

# file: qa-flow.yml
id: simple_qa
layout:
  - type: "start"
  - task: "@VarInput"
    meta:
      message: "请输入问题："
      varName: "query"
  - task: "@EmbeddingModel"
    meta:
      provider: "ollama"
      model: "bge-m3"
      apiUrl: "http://127.0.0.1:11434/api/embed"
  - task: "@InMemoryRepository"
    meta:
      query: "${query}"
      topK: 3
      splitPipeline:
        - "org.noear.solon.ai.rag.splitter.RegexTextSplitter"
        - "org.noear.solon.ai.rag.splitter.TokenSizeTextSplitter"
  - task: "@ChatModel"
    meta:
      systemPrompt: "你是一个知识库助手"
      stream: false
      chatConfig:
        provider: "ollama"
        model: "qwen2.5:1.5b"
        apiUrl: "http://127.0.0.1:11434/api/chat"
  - task: "@ConsoleOutput"
    meta:
      message: "回答：${output}"

Java 调用：

FlowEngine flowEngine = FlowEngine.newInstance();
flowEngine.eval("simple_qa");

8.3 项目实战

实战任务：智能工单处理流程

设计一个工单处理 Flow：

用户输入 -> 分类（问题/投诉/建议）-> 知识库检索 -> LLM 生成回复 -> 人工审核 -> 发送通知

第8章 注意事项

  1. Task 组件必须注册：YAML 中的 task（如 @ChatModel、@InMemoryRepository）必须是 Flow 引擎已注册的组件类名，否则会报 ComponentNotFoundException。
  2. 变量作用域：${variable} 引用必须确保前序任务已定义该变量，否则解析为 null 或空字符串，建议使用 @VarOutput 显式声明输出。
  3. FlowEngine 线程安全：默认 FlowEngine.newInstance() 为单例，若多线程并发执行同一 Flow，注意检查共享状态是否安全。
  4. splitPipeline 顺序执行：切分管道中的多个 Splitter 是链式顺序执行，后一个接收前一个的输出，不是并行处理。
  5. 复杂逻辑慎写 YAML：条件分支超过 3 层时，建议封装为自定义 Task 组件，避免在 YAML 中堆积复杂 SpEL 表达式。

第8章 实战作业

作业1：基础巩固

编写一个完整的"问答 Flow"（YAML + Java 调用），流程如下：

VarInput → EmbeddingModel → InMemoryRepository → ChatModel → ConsoleOutput

要求：知识库来源为本地 README.md 文件。

作业2：拓展应用

在 Flow 中添加 条件分支： - 使用 @IfElse 组件判断检索结果的最高相似度 - 相似度 > 0.7：进入 @ChatModel 生成回答 - 相似度 <= 0.7：输出"知识库暂无答案，请联系人工客服"

作业3：动手实践

实现一个"多轮对话 Flow"： - 使用 @ChatModel 的 stream: true 开启流式 - 通过 @SessionVar 保存对话历史（最多 5 轮） - 流式输出过程中实时显示 [token: xxx] 计数
