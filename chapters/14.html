14.1 理论讲解

14.1.1 企业知识管理痛点与解决方案

典型痛点： 1. 文档散落：PDF/Word/Excel/PPT 分散在各部门共享盘、邮件、聊天记录中 2. 查找困难：员工平均每周花费 5+ 小时查找政策、流程、历史案例 3. 知识老化：文档更新后旧版本仍在流传，缺乏版本控制 4. 新人上手慢：培训材料零散，新人需要 3-6 个月才能独立工作 5. 专家瓶颈：资深员工的知识无法有效沉淀和传承

Solon-AI 解决方案： - 摄取层：solon-ai-rag-loaders 支持 7 种格式自动解析 - 检索引擎：solon-ai-rag-repositorys + Elasticsearch 混合检索 - 权限层：solon-ai-harness + Talents 实现 RBAC/ABAC - 审计层：Talents 中的 audit + mail 实现操作日志和通知

14.1.3 核心组件详解

1. 文档摄取管道（Ingestion Pipeline）

原始文件 → 格式检测 → 解析器选择 → 文本提取 → 元数据提取 → 切分策略 → 向量化 → 存储

关键设计： - 格式检测：基于文件魔数（magic number）而非扩展名 - 切分策略： - 标题级别切分（H1/H2/H3） - 段落切分（500 tokens，50 overlap） - 表格保留（不切分表格内容） - 代码块保留（保留语法高亮信息） - 向量化：批量处理，单次最多 100 个 chunk

2. 混合检索引擎（Hybrid Search）

用户查询 → 向量化 → 并行检索 → RRF融合 → 重排序 → 返回结果
  • 向量检索：pgvector，余弦相似度，Top 20
  • 关键词检索：Elasticsearch BM25，Top 20
  • RRF 融合：k=60，合并后取 Top 10
  • 重排序：Cross-Encoder 模型精排

3. 多租户权限模型

维度 示例 实现方式
部门 研发部/市场部/财务部 文档 metadata.department
角色 员工/经理/高管 用户角色标签
密级 公开/内部/机密/绝密 文档 classification + 用户 clearance

4. 引用溯源机制

  • 返回答案时附带参考段落原文
  • 高亮显示参考位置（页码/章节）
  • 支持"跳转到原文"功能

14.1.4 关键技术决策

Q1：为什么选 pgvector 而非 Elasticsearch 做为主向量库？

维度 pgvector Elasticsearch
部署成本 低（复用现有 PostgreSQL） 高（需独立部署 ES 集群）
查询性能 10万级向量毫秒级 百万级向量毫秒级
事务支持 强（ACID） 弱（最终一致）
生态融合 好（Solon 数据访问层） 一般
适用规模 10万-100万向量 100万+ 向量

结论：中小规模（<100万向量）pgvector 性价比最高；大规模考虑 ES 或 Milvus。

Q2：文档切分策略如何选择？

策略 适用场景 优点 缺点
固定长度 通用 实现简单 可能切断语义
标题级别 结构化文档 保留语义 chunk 大小不均
语义切分 高质量需求 语义完整 计算成本高
表格保留 含表格文档 表格不破碎 实现复杂

推荐：标题级别为主，段落切分为辅，表格和代码块强制保留。

Q3：向量化模型选型

模型 维度 大小 适用场景
bge-m3 1024 2GB 多语言、通用（推荐）
nomic-embed-text 768 500MB 英文为主
text-embedding-3-small 1536 - OpenAI 生态

推荐：bge-m3（多语言支持好，本地部署，符合国内合规）。

@Singleton
public class DocumentIngestionService {
    private final List<DocumentLoader> loaders;
    private final EmbeddingModel embeddingModel;
    private final VectorRepository repository;

    @Inject
    public DocumentIngestionService(List<DocumentLoader> loaders,
                                    EmbeddingModel embeddingModel,
                                    VectorRepository repository) {
        this.loaders = loaders;
        this.embeddingModel = embeddingModel;
        this.repository = repository;
    }

    public IngestionResult ingest(MultipartFile file) throws Exception {
        // 1. 格式检测
        String mimeType = detectMimeType(file.getInputStream());

        // 2. 选择解析器
        DocumentLoader loader = loaders.stream()
                .filter(l -> l.supports(mimeType))
                .findFirst()
                .orElseThrow(() -> new IllegalArgumentException("Unsupported format: " + mimeType));

        // 3. 解析文档
        Document document = loader.load(file.getInputStream());

        // 4. 切分
        List<TextSplit> splits = splitDocument(document);

        // 5. 向量化（批量）
        List<Embedding> embeddings = embeddingModel.embed(
            splits.stream().map(TextSplit::getText).toList()
        );

        // 6. 存储
        for (int i = 0; i < splits.size(); i++) {
            repository.save(new DocumentChunk(splits.get(i), embeddings.get(i)));
        }

        return IngestionResult.success(splits.size());
    }

    private String detectMimeType(InputStream is) throws IOException {
        byte[] header = is.readNBytes(16);
        is.close();
        return TikaFactory.detect(header);
    }
}

关键工程细节： - 使用 Apache Tika 做格式检测（基于文件魔数） - 批量向量化减少 LLM 调用次数 - 异常处理：格式不支持、文件过大、解析失败

练习2：混合检索引擎

目标：实现向量检索 + 关键词检索 + RRF 融合

@Singleton
public class HybridSearchEngine {
    private final VectorRepository vectorRepo;
    private final ElasticsearchClient esClient;
    private final EmbeddingModel embeddingModel;
    private final RerankingModel rerankingModel; // 可选

    @Inject
    public HybridSearchEngine(VectorRepository vectorRepo,
                             ElasticsearchClient esClient,
                             EmbeddingModel embeddingModel) {
        this.vectorRepo = vectorRepo;
        this.esClient = esClient;
        this.embeddingModel = embeddingModel;
    }

    public List<ScoredDocument> search(String query, SearchOptions options) {
        // 1. 向量检索（语义相似度）
        Embedding queryEmbedding = embeddingModel.embed(query);
        List<ScoredDocument> vectorResults = vectorRepo.search(
            queryEmbedding, options.getTopK() * 2
        );

        // 2. 关键词检索（BM25）
        List<ScoredDocument> keywordResults = esClient.search(
            query, options.getTopK() * 2
        );

        // 3. RRF 融合
        List<ScoredDocument> fused = rrfFusion(vectorResults, keywordResults, 60);

        // 4. 重排序（可选）
        if (rerankingModel != null && options.isRerank()) {
            fused = rerank(fused, query);
        }

        return fused.stream().limit(options.getTopK()).toList();
    }

    private List<ScoredDocument> rrfFusion(
            List<ScoredDocument> results1,
            List<ScoredDocument> results2,
            int k) {
        Map<String, ScoredDocument> merged = new HashMap<>();

        for (int rank = 0; rank < results1.size(); rank++) {
            String id = results1.get(rank).getId();
            double score = 1.0 / (k + rank + 1);
            merged.computeIfAbsent(id, key -> new ScoredDocument(id))
                  .addScore(score, "vector");
        }

        for (int rank = 0; rank < results2.size(); rank++) {
            String id = results2.get(rank).getId();
            double score = 1.0 / (k + rank + 1);
            merged.computeIfAbsent(id, key -> new ScoredDocument(id))
                  .addScore(score, "keyword");
        }

        return merged.values().stream()
                .sorted(Comparator.comparingDouble(ScoredDocument::getTotalScore).reversed())
                .limit(10)
                .collect(Collectors.toList());
    }
}

关键工程细节： - RRF（Reciprocal Rank Fusion）参数 k=60 是经验值 - 双路检索各取 Top 20，融合后取 Top 10 - 重排序使用 Cross-Encoder 模型（如 bge-reranker）

练习3：RBAC 权限拦截器

目标：基于部门/角色/密级的访问控制

@Singleton
public class PermissionInterceptor implements HandlerInterceptor {

    @Override
    public boolean beforeHandle(Invocation inv) {
        // 1. 获取当前用户
        User currentUser = SecurityContext.getCurrentUser();

        // 2. 获取资源权限要求
        DocumentRequest request = inv.getArgument(0);
        Document document = repository.findById(request.getDocumentId());

        // 3. 部门匹配
        if (!hasDepartmentAccess(currentUser, document)) {
            throw new AccessDeniedException("无部门访问权限");
        }

        // 4. 密级匹配
        if (!hasClearanceLevel(currentUser, document)) {
            throw new AccessDeniedException("密级不足");
        }

        // 5. 角色匹配
        if (!hasRolePermission(currentUser, document.getRequiredRole())) {
            throw new AccessDeniedException("角色权限不足");
        }

        return true;
    }

    private boolean hasDepartmentAccess(User user, Document doc) {
        // 管理员可访问所有
        if (user.hasRole("ADMIN")) return true;
        // 文档所属部门或用户所在部门匹配
        return user.getDepartmentIds().contains(doc.getDepartmentId());
    }

    private boolean hasClearanceLevel(User user, Document doc) {
        // 密级：公开(0) < 内部(1) < 机密(2) < 绝密(3)
        return user.getClearanceLevel() >= doc.getClassification();
    }
}

练习4：引用溯源中间件

目标：返回答案时附带参考段落和页码

@Singleton
public class CitationMiddleware {

    public ChatResponse withCitation(ChatRequest request, List<ScoredDocument> docs) {
        // 1. 构造带引用的 Prompt
        String context = buildCitedContext(docs);

        ChatMessage message = ChatMessage.ofUserAugment(request.getQuery(), context);

        // 2. 调用 LLM
        ChatResponse response = chatModel.prompt(message).call();

        // 3. 附加引用信息
        response.setCitations(docs.stream()
                .map(doc -> new Citation(
                    doc.getDocumentId(),
                    doc.getPageNumber(),
                    doc.getParagraphIndex(),
                    doc.getText().substring(0, Math.min(200, doc.getText().length()))
                ))
                .toList());

        return response;
    }

    private String buildCitedContext(List<ScoredDocument> docs) {
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < docs.size(); i++) {
            ScoredDocument doc = docs.get(i);
            sb.append(String.format("[%d] %s (页码: %d, 相关度: %.2f)\n",
                i + 1, doc.getText(), doc.getPageNumber(), doc.getScore()));
        }
        return sb.toString();
    }
}

@Configuration

    public IngestionPipeline ingestionPipeline(

            ElasticsearchClient esClient,
            EventPublisher eventPublisher) {

                .loaders(loaders)
                .splitter(splitter)
                .embedding(embeddingModel)
                .vectorRepo(vectorRepo)
                .esClient(esClient)
                .eventPublisher(eventPublisher)
                .build();
    }

@Singleton
public class IngestionPipeline {
    // 配置参数
    private static final int BATCH_SIZE = 100;
    private static final int CHUNK_SIZE = 500;
    private static final int CHUNK_OVERLAP = 50;

    private final DocumentStorage storage;
    private final List<DocumentLoader> loaders;
    private final TextSplitter splitter;
    private final EmbeddingModel embeddingModel;
    private final VectorRepository vectorRepo;
    private final ElasticsearchClient esClient;
    private final EventPublisher eventPublisher;

    public IngestionResult process(MultipartFile file, String userId) throws Exception {
        long start = System.currentTimeMillis();

        // 1. 存储原始文件
        String fileId = storage.store(file);

        // 2. 格式检测与解析
        String mimeType = detectMimeType(file.getInputStream());
        DocumentLoader loader = loaders.stream()
                .filter(l -> l.supports(mimeType))
                .findFirst()
                .orElseThrow(() -> new UnsupportedFormatException(mimeType));

        Document document = loader.load(file.getInputStream());

        // 3. 元数据提取
        DocumentMetadata metadata = extractMetadata(document, file, userId);

        // 4. 切分（保留结构）
        List<TextSplit> splits = splitter.split(document, DocumentSplitOptions.builder()
                .chunkSize(CHUNK_SIZE)
                .overlap(CHUNK_OVERLAP)
                .preserveHeaders(true)
                .preserveTables(true)
                .preserveCodeBlocks(true)
                .build());

        // 5. 批量向量化
        List<Embedding> embeddings = batchEmbed(splits);

        // 6. 批量存储（pgvector）
        List<DocumentChunk> chunks = new ArrayList<>();
        for (int i = 0; i < splits.size(); i++) {
            chunks.add(new DocumentChunk(splits.get(i), embeddings.get(i), metadata));
        }
        vectorRepo.batchSave(chunks);

        // 7. 同步到 ES（全文检索）
        esClient.indexDocument(document, metadata);

        // 8. 发布事件（异步通知）
        eventPublisher.publish(new DocumentIngestedEvent(document.getId(), splits.size()));

        long duration = System.currentTimeMillis() - start;
        log.info("Document ingested: id={}, chunks={}, duration={}ms", 
            document.getId(), splits.size(), duration);

        return IngestionResult.success(document.getId(), splits.size(), duration);
    }

    private List<Embedding> batchEmbed(List<TextSplit> splits) {
        // 分批处理，每批 BATCH_SIZE 个
        List<Embedding> allEmbeddings = new ArrayList<>();
        for (int i = 0; i < splits.size(); i += BATCH_SIZE) {
            int end = Math.min(i + BATCH_SIZE, splits.size());
            List<String> texts = splits.subList(i, end).stream()
                    .map(TextSplit::getText)
                    .toList();
            allEmbeddings.addAll(embeddingModel.embed(texts));
        }
        return allEmbeddings;
    }
}

模块2：混合检索引擎

@Singleton
public class HybridSearchEngine {
    private static final int RRF_K = 60;
    private static final int RETRIEVAL_TOP_K = 20;
    private static final int FINAL_TOP_K = 10;

    private final VectorRepository vectorRepo;
    private final ElasticsearchClient esClient;
    private final EmbeddingModel embeddingModel;
    private final RerankingModel rerankingModel;
    private final CacheManager cacheManager;

    @Inject
    public HybridSearchEngine(VectorRepository vectorRepo,
                             ElasticsearchClient esClient,
                             EmbeddingModel embeddingModel,
                             @Nullable RerankingModel rerankingModel,
                             CacheManager cacheManager) {
        this.vectorRepo = vectorRepo;
        this.esClient = esClient;
        this.embeddingModel = embeddingModel;
        this.rerankingModel = rerankingModel;
        this.cacheManager = cacheManager;
    }

    public List<ScoredDocument> search(String query, SearchContext context) {
        // 1. 检查缓存
        String cacheKey = "search:" + DigestUtil.sha256(query + context.getUserId());
        List<ScoredDocument> cached = cacheManager.get(cacheKey);
        if (cached != null) {
            log.debug("Cache hit for query: {}", query);
            return cached;
        }

        // 2. 向量检索
        Embedding queryEmbedding = embeddingModel.embed(query);
        List<ScoredDocument> vectorResults = vectorRepo.search(queryEmbedding, RETRIEVAL_TOP_K)
                .stream()
                .filter(doc -> hasPermission(context.getUser(), doc))
                .toList();

        // 3. 关键词检索
        List<ScoredDocument> keywordResults = esClient.search(query, RETRIEVAL_TOP_K)
                .stream()
                .filter(doc -> hasPermission(context.getUser(), doc))
                .toList();

        // 4. RRF 融合
        List<ScoredDocument> fused = rrfFusion(vectorResults, keywordResults, RRF_K);

        // 5. 重排序（可选）
        if (rerankingModel != null && context.isRerank()) {
            fused = rerank(fused, query);
        }

        // 6. 缓存结果（5分钟）
        List<ScoredDocument> result = fused.stream().limit(FINAL_TOP_K).toList();
        cacheManager.put(cacheKey, result, Duration.ofMinutes(5));

        return result;
    }

    private boolean hasPermission(User user, ScoredDocument doc) {
        // 权限过滤逻辑（见练习3）
        return true; // 简化示例
    }
}

模块3：问答 API（带引用）

@RestController
@RequestMapping("/api/chat")
public class KnowledgeChatController {
    private final HybridSearchEngine searchEngine;
    private final ChatModel chatModel;
    private final CitationMiddleware citationMiddleware;
    private final MetricsService metricsService;

    @Inject
    public KnowledgeChatController(HybridSearchEngine searchEngine,
                                   ChatModel chatModel,
                                   CitationMiddleware citationMiddleware,
                                   MetricsService metricsService) {
        this.searchEngine = searchEngine;
        this.chatModel = chatModel;
        this.citationMiddleware = citationMiddleware;
        this.metricsService = metricsService;
    }

    @Post
    public ChatResponse chat(@Body ChatRequest request, HttpServletRequest httpRequest) {
        long start = System.currentTimeMillis();
        User user = SecurityContext.getCurrentUser();

        try {
            // 1. 检索
            List<ScoredDocument> docs = searchEngine.search(
                request.getQuery(),
                SearchContext.builder()
                    .user(user)
                    .rerank(request.isRerank())
                    .build()
            );

            // 2. 构造 Prompt（带引用）
            ChatResponse response = citationMiddleware.withCitation(request, docs);

            // 3. 记录指标
            long latency = System.currentTimeMillis() - start;
            metricsService.recordQuery(latency, docs.size());

            return response;
        } catch (Exception e) {
            log.error("Chat failed: query={}, user={}", request.getQuery(), user.getId(), e);
            throw e;
        }
    }
}

模块5：质量评估

@Singleton
public class QualityEvaluationService {
    private final FeedbackRepository feedbackRepo;
    private final MetricsCalculator metricsCalculator;

    public void recordFeedback(String queryId, boolean thumbsUp, @Nullable String comment) {
        Feedback feedback = new Feedback(queryId, thumbsUp, comment);
        feedbackRepo.save(feedback);

        // 计算实时指标
        double thumbsUpRate = metricsCalculator.calculateThumbsUpRate(queryId);
        log.info("Query {} thumbs up rate: {}%", queryId, String.format("%.2f", thumbsUpRate * 100));
    }

    public QualityReport generateReport(DateRange range) {
        // 统计指标
        long totalQueries = feedbackRepo.count(range);
        double avgLatency = metricsCalculator.calculateAvgLatency(range);
        double thumbsUpRate = metricsCalculator.calculateThumbsUpRate(range);
        Map<String, Integer> topQueries = metricsCalculator.getTopQueries(range);

        return QualityReport.builder()
                .totalQueries(totalQueries)
                .avgLatency(avgLatency)
                .thumbsUpRate(thumbsUpRate)
                .topQueries(topQueries)
                .build();
    }
}
