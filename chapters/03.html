  • Few-Shot Prompting：通过示例引导模型输出
  • Chain-of-Thought：让模型逐步推理

3.1.2 ChatSession 会话管理

Solon-AI 提供 ChatSession 接口，支持：

  • 会话生命周期管理（创建、销毁、过期）
  • 会话级上下文隔离
  • 持久化（Redis / 数据库）

3.2 实践练习

练习1：动态 Template Prompt

import org.noear.solon.ai.chat.ChatModel;
import org.noear.solon.ai.chat.ChatMessage;

public class TemplatePrompt {
    public static void main(String[] args) {
        ChatModel chatModel = ChatModel.of("http://127.0.0.1:11434/api/chat")
                .provider("ollama")
                .model("qwen2.5:1.5b")
                .build();

        String template = "你是一位{role}，请回答关于{topic}的问题。"
                + "要求：{requirement}";

        String prompt = template.replace("{role}", "资深律师")
                .replace("{topic}", "劳动合同")
                .replace("{requirement}", "用通俗易懂的语言解释，避免专业术语");

        String response = chatModel.prompt(prompt)
                .call()
                .getMessage()
                .getContent();

        System.out.println(response);
    }
}

练习2：会话管理（ChatSession）

import org.noear.solon.ai.chat.session.ChatSession;
import org.noear.solon.ai.chat.session.ChatSessionManager;

public class SessionDemo {
    public static void main(String[] args) {
        ChatSessionManager sessionManager = ChatSessionManager.of(chatModel);

        // 创建会话
        ChatSession session = sessionManager.createSession("user_001");

        // 发送消息（自动管理上下文）
        String response1 = session.chat("我叫张三").getMessage().getContent();
        String response2 = session.chat("我叫什么？").getMessage().getContent();

        System.out.println("AI: " + response2); // 应该记住"张三"
    }
}

3.3 项目实战

实战任务：Prompt 模板引擎

实现一个简单的 Prompt 模板引擎，支持： - 变量替换 {variable} - 条件渲染 {#if condition}...{/if} - 循环渲染 {#each items}...{/each}

第3章 注意事项

  1. ChatSession 生命周期：默认 ChatSession 是内存级实现，应用重启后会话丢失；生产环境需接入 Redis 或数据库持久化。
  2. 变量名冲突：String.replace() 会替换所有匹配子串，若模板变量名存在包含关系（如 {name} 与 {name_full}），需先替换长变量名，再替换短变量名。
  3. System Prompt 顺序：在 List<ChatMessage> 中，system 消息必须放在最前面，否则模型可能无法正确识别角色设定。
  4. 上下文窗口限制：不同模型 token 上限不同（如 qwen2.5 支持 128k），超出后会截断或抛出异常，需自行做消息裁剪或摘要。
  5. ofUserAugment 引用长度：ChatMessage.ofUserAugment() 会将检索文档自动拼入 prompt，注意控制引用片段总长度，避免挤占模型推理空间。

第3章 实战作业

作业1：基础巩固

实现一个 PromptTemplate 工具类，支持以下功能： - render(template, Map<String, Object> vars)：变量替换 - 当变量缺失时抛出 IllegalArgumentException 而非静默忽略

作业2：拓展应用

为模板引擎添加默认值语法：{name:默认值}，当变量 map 中不存在 name 时使用默认值；支持嵌套 Map 访问，如 {user.name}。

作业3：动手实践

实现一个带会话持久化的聊天服务： - 使用 Redis 存储 ChatSession（可借助 solon-ai-harness 中的 memory talent） - 提供 POST /api/chat/session 接口，参数包含 sessionId、message - 支持查看会话历史 GET /api/chat/session/{sessionId}/history
