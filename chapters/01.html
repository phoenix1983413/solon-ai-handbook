1.1 理论讲解

1.1.1 Solon-AI 是什么？

Solon-AI 是 Solon 生态的 AI 开发框架，提供：

  • 统一 LLM 接口：ChatModel 抽象屏蔽不同供应商差异
  • 多模型方言：OpenAI、Gemini、Claude、Ollama、DeepSeek、DashScope
  • Agent 引擎：ReAct 自省推理 + Team 多智能体协作
  • RAG 全链路：从文档加载到向量检索的一站式方案
  • MCP 协议：Model Context Protocol 深度集成
  • 低代码编排：YAML 驱动的 AI Flow（类似 Dify）

1.1.2 核心架构（三层模型）

│  框架层（Solon-AI Framework）            │

│  - MCP Server / Client                   │
│  - Talents 插件体系                      │
└─────────────────────────────────────────┘
                    ↓

│  基础设施层（Infrastructure）             │
│  - LLM 供应商（OpenAI/Ollama/DeepSeek）  │
│  - 向量数据库（pgvector/Milvus/Qdrant）  │
│  - 文档存储（MySQL/ES/Redis）             │
└─────────────────────────────────────────┘

1.2 实践练习

练习1：环境搭建

步骤1：创建 Maven 项目

<!-- pom.xml -->
<parent>
    <groupId>org.noear</groupId>
    <artifactId>solon-ai-parent</artifactId>
    <version>4.1.1</version>
</parent>

<dependencies>
    <!-- 核心模块：包含所有 dialects -->
    <dependency>
        <groupId>org.noear</groupId>
        <artifactId>solon-ai</artifactId>
    </dependency>

    <!-- Agent 模块（可选） -->
    <dependency>
        <groupId>org.noear</groupId>
        <artifactId>solon-ai-agent</artifactId>
    </dependency>

    <!-- MCP 模块（可选） -->
    <dependency>
        <groupId>org.noear</groupId>
        <artifactId>solon-ai-mcp</artifactId>
    </dependency>
</dependencies>

步骤2：配置 application.yml

server:
  port: 8080

solon:
  ai:
    chat:
      default_provider: ollama
      default_model: qwen2.5:1.5b
      api_url: http://127.0.0.1:11434/api/chat

步骤3：编写启动类

import org.noear.solon.Solon;

public class App {
    public static void main(String[] args) {
        Solon.start(App.class, args);
    }
}

练习2：第一个 Hello World

import org.noear.solon.ai.chat.ChatModel;
import org.noear.solon.ai.chat.ChatMessage;
import org.noear.solon.ai.chat.ChatResponse;

public class HelloWorld {
    public static void main(String[] args) {
        // 1. 构建 ChatModel
        ChatModel chatModel = ChatModel.of("http://127.0.0.1:11434/api/chat")
                .provider("ollama")
                .model("qwen2.5:1.5b")
                .build();

        // 2. 发送消息
        ChatResponse response = chatModel.prompt("你好，请用一句话介绍你自己")
                .call();

        // 3. 输出结果
        System.out.println(response.getMessage());
    }
}

运行方式（需先启动 Ollama）：

# 1. 启动 Ollama
ollama serve

# 2. 拉取模型
ollama pull qwen2.5:1.5b

# 3. 运行 Java 程序
mvn spring-boot:run

1.3 项目实战

实战任务：多供应商切换

实现一个简单的命令行工具，支持在 OpenAI、Ollama、DeepSeek 之间无缝切换：

public class MultiProviderDemo {
    public static void main(String[] args) {
        // OpenAI
        ChatModel openai = ChatModel.of("https://api.openai.com/v1/chat")
                .provider("openai")
                .apiKey("your-openai-key")
                .model("gpt-4o")
                .build();

        // DeepSeek
        ChatModel deepseek = ChatModel.of("https://api.deepseek.com/v1/chat")
                .provider("openai")  // 兼容 OpenAI 协议
                .apiKey("your-deepseek-key")
                .model("deepseek-chat")
                .build();

        // Ollama（本地）
        ChatModel ollama = ChatModel.of("http://127.0.0.1:11434/api/chat")
                .provider("ollama")
                .model("qwen2.5:1.5b")
                .build();

        // 测试三个模型
        String prompt = "用一句话解释什么是 AI Agent";

        System.out.println("=== OpenAI ===");
        System.out.println(openai.prompt(prompt).call().getMessage());

        System.out.println("=== DeepSeek ===");
        System.out.println(deepseek.prompt(prompt).call().getMessage());

        System.out.println("=== Ollama ===");
        System.out.println(ollama.prompt(prompt).call().getMessage());
    }
}

第1章 注意事项

  1. 版本稳定性：当前 solon-ai 处于 dev 版本，API 可能随时调整，生产使用请锁定 commit 或等待正式发布。
  2. provider 参数敏感：provider("ollama") 区分大小写，写成 "Ollama" 将无法识别对应方言。
  3. 聚合包范围误区：solon-ai 只聚合 dialects，不包含 agent / flow / mcp / talents，这些需要按需单独引入依赖。
  4. Ollama 本地地址：默认监听 127.0.0.1:11434，Docker 部署时需加 --network host 或显式映射 11434 端口。
  5. JDK 版本建议：虽然最低支持 JDK 8，但 reactive 流和虚拟线程相关特性推荐 JDK 17+。

第1章 实战作业

作业1：基础巩固

完成本章"多供应商切换"示例，在 OpenAI、Ollama、DeepSeek 三个模型上运行同一 prompt，观察响应速度和输出风格差异，将结果整理记录到 chapter1-comparison.md。

作业2：拓展应用

为 MultiProviderDemo 添加异常处理和重试机制： - 网络超时设置为 30 秒 - 失败后自动重试 3 次，采用指数退避策略 - 将运行结果写入 CSV 文件（字段：模型名、耗时、token 数、是否成功）

作业3：动手实践

搭建基于 Solon Web 的 REST 服务，暴露 POST /api/chat 接口： - 接收 JSON：{"provider":"ollama","model":"qwen2.5:1.5b","prompt":"..."} - 返回 JSON：{"content":"...","usage":{},"finishReason":"stop"} - 支持流式和非流式两种模式（通过 ?stream=true 参数控制）
