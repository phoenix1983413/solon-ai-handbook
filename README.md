> **从入门到进阶的完整学习路径**
>

## 📚 文档使用说明

本文档按 **三阶段渐进式学习** 设计：

| 阶段 | 名称 | 目标读者 | 预计耗时 |
|------|------|----------|----------|
| **第一阶段** | 基础入门 | 有 Java 基础，首次接触 AI 框架 | 1-2 周 |
| **第二阶段** | 核心进阶 | 已完成入门，想深入 Agent/RAG/MCP | 2-3 周 |
| **第三阶段** | 高级实战 | 准备生产级项目，需要架构设计能力 | 1-2 周 |

每个阶段包含：
- **理论讲解** — 核心概念与架构设计
- **实践练习** — 可运行的代码示例
- **项目实战** — 综合性练习，整合本章知识点

## 🚀 快速开始

### 环境要求

- **JDK**：8+（推荐 17+）
- **Maven**：3.6+
- **Ollama**：本地部署（可选，用于测试）

### 5 分钟快速体验

```bash
# 1. 克隆本项目
git clone https://github.com/your-username/solon-ai-handbook.git
cd solon-ai-handbook

# 2. 启动本地服务（需要 Node.js）
npm install
npm run serve

# 3. 浏览器访问
# http://localhost:8080
```

### 在线访问

📖 **GitHub Pages**: [https://your-username.github.io/solon-ai-handbook](https://your-username.github.io/solon-ai-handbook)
